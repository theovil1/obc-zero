# Writing

Texts written to be read by someone who does not know this project.

**These are not reports.** `docs/reports/` holds append-only history: dated,
tied to a commit, never edited, superseded only by a newer report. That
property is worth protecting, and a text meant to be revised and rewritten for
clarity would erode it.

So the two are kept apart. What lives here may be edited freely. It cites the
reports for figures rather than restating them, because a number copied out of
an archive stops being the archive's number the first time either changes.
